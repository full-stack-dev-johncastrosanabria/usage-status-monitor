# v0.2 Complete Panel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v0.2 — native interfaces on macOS, Windows and Linux, GitHub Copilot as a provider, installers on GitHub Releases and a launch README.

**Architecture:** The Python backend (`src/usage_monitor`) collects a `Snapshot` and serves it as JSON on 127.0.0.1; every interface (web panel, SwiftUI, WPF, GTK4, CLI, plugin hook) only renders that JSON. Copilot is one more provider module with a pure `parse()` and a `fetch()`; a tag-triggered workflow packages each interface with the PyInstaller backend.

**Tech Stack:** Python 3.12+ stdlib only (uv, ruff, mypy --strict, pytest), SwiftUI (macOS 14+), WPF .NET 8, GTK4 (PyGObject or C — whatever the Linux branch shipped), PyInstaller, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-12-v0.2-complete-panel-design.md`

## Global Constraints

- No runtime dependencies in the Python package; stdlib only.
- Credentials are read only, never refreshed, and only sent to their own provider.
- Every user-facing string exists in en, es and zh (`tests/test_i18n.py`, `tests/test_panel.py` enforce it).
- `uv run ruff check`, `uv run ruff format --check`, `uv run mypy`, `uv run pytest` pass before every commit.
- Installers are unsigned; the README warning stays.
- Screenshots and the GIF use demo data only (`USAGE_MONITOR_DEMO=1`); no real emails.
- Commits end with the `Claude-Session:` trailer; never use port 8787 for tests (the owner's live server).

## Review Focus

1. Copilot signed in with a token that has no Copilot subscription (HTTP 404/403) → the provider shows a readable error, the rest of the panel works. Test in Task 1.
2. Copilot Business/Enterprise with every quota `unlimited` → shows "unlimited" instead of an empty block. Test in Task 1.
3. An older server JSON without `copilot` opened by a newer native app → the app still decodes. Swift `copilot` is optional (Task 3).
4. A tag pushed while CI is red → the release must not publish. Release job depends on the test job (Task 6).
5. `gh` installed but not logged in → `gh auth token` exits non-zero; treated as "not signed in", no traceback. Test in Task 1.

```python
"""GitHub Copilot monthly quotas, with the token the Copilot extensions or `gh` already store."""

from __future__ import annotations

import json
import os
import shutil
import subprocess
import sys
from datetime import UTC, datetime
from pathlib import Path
from typing import Any

from ..config import HOME
from ..http import request_json
from ..i18n import tr
from ..models import ProviderError, Usage, Window
from ..system import QUIET

URL = "https://api.github.com/copilot_internal/user"  # what the official extensions call; undocumented
# (key, label, blocks): premium requests are the scarce monthly allowance
QUOTAS = (("premium_interactions", "Premium requests", True), ("chat", "Chat", False), ("completions", "Completions", False))


def _config_dir() -> Path:
    if sys.platform == "win32" and (local := os.environ.get("LOCALAPPDATA")):
        return Path(local) / "github-copilot"
    return HOME / ".config" / "github-copilot"


def _gh_token() -> str | None:
    if not (gh := shutil.which("gh")):
        return None
    try:
        out = subprocess.run([gh, "auth", "token"], capture_output=True, text=True, timeout=10, check=False, **QUIET)
    except (OSError, subprocess.TimeoutExpired):
        return None
    return out.stdout.strip() or None if out.returncode == 0 else None


def token() -> str | None:
    for name in ("apps.json", "hosts.json"):
        try:
            data = json.loads((_config_dir() / name).read_text(encoding="utf-8"))
        except (OSError, ValueError):
            continue
        for entry in data.values() if isinstance(data, dict) else ():
            if isinstance(entry, dict) and isinstance(t := entry.get("oauth_token"), str) and t:
                return t
    return _gh_token()


def _reset(value: Any) -> datetime | None:
    try:
        return datetime.fromisoformat(value).replace(tzinfo=UTC) if isinstance(value, str) else None
    except ValueError:
        return None


def parse(data: dict[str, Any]) -> Usage:
    snaps = data.get("quota_snapshots") or {}
    resets = _reset(data.get("quota_reset_date"))
    windows = tuple(
        Window(tr(label), 100.0 - float(q.get("percent_remaining") or 0), resets, blocking=blocks)
        for key, label, blocks in QUOTAS
        if isinstance(q := snaps.get(key), dict) and not q.get("unlimited")
    )
    return Usage(str(data.get("copilot_plan", "?")), windows or (Window(tr("Unlimited"), 0.0, None, blocking=False),))


def fetch() -> Usage:
    if not (t := token()):
        raise ProviderError(tr("not signed in; run `gh auth login` or sign in to Copilot in your editor"))
    data = request_json(URL, {"Authorization": "token " + t, "Accept": "application/json"})
    if not isinstance(data, dict):
        raise ProviderError(tr("unexpected response from the server"))
    return parse(data)
```

Note: GitHub sends `quota_reset_date` as a bare date (`2026-12-01`), read as midnight UTC. If it ever sends a
full timestamp with an offset, change `_reset` to keep that offset instead of replacing it.
